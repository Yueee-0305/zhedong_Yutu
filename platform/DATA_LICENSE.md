# 代码开源与资料使用边界

根目录 MIT 许可证适用于本项目原创程序与开发说明，不自动覆盖以下内容：

- `data/catalog.json` 与构建产物内的遗产资料、原表摘录及其来源；
- `data/zhejiang.json`：来源于阿里云 DataV 的浙江边界；
- `public/design-reference.png`：用户提供的设计参考；
- 后续加入的照片、舆图、扫描件或第三方文件。

数据库包含第三方文字摘录，尚未逐项确认其开放许可。不能将本项目的 MIT
许可证理解为对所有史料文字、图像或地理资料的再许可。当前代码是开源代码，
资料仍属于待审核的研究快照，不宣称整个数据库已作为开放数据授权。

发布到公开仓库前，可使用：

```
node scripts/release.cjs --public
```

该模式保留遗产 ID、名称、分类、地区、原表坐标、状态等字段，移除原文摘录、
地址描述、媒体、质检叙述等研究内容，并在快照中标记 public-metadata。
公开精简模式仍需复核分类与坐标；既有事实不因转换而变成审核结论。
边界数据与参考设计图也从精简包排除：地图可显示坐标点，但不再绘制行政区轮廓。
待逐项确认许可后，可由维护者补入原始材料或自撰且有出处的介绍。

第三方 Leaflet 使用 BSD-2-Clause，完整许可在 `public/vendor/LICENSE`。
