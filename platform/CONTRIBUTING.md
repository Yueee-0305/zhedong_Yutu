# 参与完善

欢迎修复程序、改善可访问性、补充有出处的遗产资料。

1. Fork 仓库，在新分支修改。
2. 原创前端代码修改 `src/`，数据修改 `data/`，不要仅修改生成的 `dist/`。
3. 运行 `npm run build` 和 `npm test`。无需安装 npm 依赖。
4. 提交 Pull Request，写明目的、改变的行为、验收结果。

## 资料修订

- 每处遗产使用稳定遗产 ID，不以名称为唯一键。
- 原文与自撰概括分开；提供书名、版本、卷页或来源链接。
- 不因名称相似、点位接近而自动合并记录。
- 坐标需注明坐标系、来源和定位精度；未知值保留待核。
- 包含关系与历史军事隶属分开，并补充时段与依据。
- 无权限再发布的扫描件或长篇摘录不要加入公开仓库。
- 修订可通过“遗产资料纠错”Issue 提出，维护者复核后再合并。

## 发布

GitHub Pages 由 main 分支构建 `dist/`。研究完整版和公开精简版都需复核实际发布范围。
代码许可证不自动授予第三方研究资料的开放许可。
