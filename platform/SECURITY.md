# 配置与安全

不要向仓库、网页设置、截图或 Issue 提交模型 API 密钥。
模型密钥仅放在服务器环境变量 `LLM_API_KEY`；`.env` 已加入忽略列表。
站点访问口令与模型 API 密钥是不同的值。

可选后端默认仅在 127.0.0.1 监听。正式对外运行应使用 HTTPS 反向代理，
设置 PUBLIC_ORIGIN、ATLAS_ACCESS_TOKEN，并在代理层增加访问控制和请求限制。
后端内置每个连接来源每分钟 20 次请求限制；它不能替代生产级账户配额系统。
默认不采信 X-Forwarded-For，反向代理下可能共享限额，需由部署者在代理层处理。

默认仅将“已审核”“已复核”“审核通过”的匹配记录发送给模型。
当前资料均待复核；如私有研究确需试用，维护者自行设置 ALLOW_UNREVIEWED_AI=true。
这不会使原始资料获得公开或开放许可。

检索材料视为不可信内容；系统提示词禁止将资料中的文字当作指令。
引用 ID 校验只能检测未知引用，不能保证模型每个句子均获证据支持。
涉及学术结论仍应回看原文。
