## 历史地理解释边界

- 1582 年图层是历史地理研究复原成果，**不是明代实测地图**；不能直接套用于明初、嘉靖中期或崇祯期的全部行政与军事制度。
- 明代府县边界是民政层级，地图中的卫、所、巡检司、烽堠关系另须史料核对；历史图层中的行政边界不等同于卫所防区边界。
- 347 条名录涵盖历时见载的历史设施和候选条目，**不是任何单一年份同时存在的数量**。
- 可定位点位共 59 条，其中 43 条对应原表现存遗址记录，16 条为候选位置。这里的坐标定位于现存遗址或候选点，不一定对应历史机构在某一时期的营署中心。未定位条目继续保留在左侧清单。
- 明代组织结构的主要文献底本为《浙江通志》卷九十五《海防一》、卷九十七《海防三》、卷九十八《海防四》，卫制对读《明史》卷九十；逐条校核以设施属性字段为准。

## 用法

页面默认显示卫星影像；右上角可切换为 OpenStreetMap 或明代行政底图，也可直接在卫星影像上开启 1582 年行政区划叠加，使用透明度滑块对照古今地理。点击点位可查看现存遗址、历史名录、定位状态与史料。手机端控制区可滚动浏览。

## 技术

静态 Leaflet 页面、现代卫星及 OSM 瓦片、中央研究院官方 WMTS。依赖外部服务在线访问，不保证所有地区、放大级别和网络环境均可加载。
