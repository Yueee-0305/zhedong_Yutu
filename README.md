# 明代浙江舆图｜浙东六卫与所属所城交互

[进入舆图交互](https://yueee-0305.github.io/zhedong_Yutu/) · [图文名称对应 JSON](assets/historical-map-verified.json) · [CSV 数据](assets/historical-map-verified.csv)

## 本轮范围

从《明代浙江舆图》（1600 × 1220 像素）可以辨认的名称出发，与此前《明代浙东海防建制_五府历史方位与GIS精定位版.xlsx》和《浙东海防遗址.xlsx》中的历史建置与遗址资料进行名称匹配。

本轮六卫组织范围是：临山卫、观海卫、定海卫、昌国卫、海门卫、松门卫，以及原建制表中的18个直属所级建置。

当前发布 **13 个图上文字锚点**：5 个卫级标注（临山卫、观海卫、定海卫、昌国卫、海门卫）和8个所级/合称标注（三山所、爵溪所、石浦二所、健跳所、桃渚所、新河所、楚门所、隘顽所）。松门卫组织分组下已有2个所城锚点，但没有为松门卫本级添加缺少图中文字的独立标记。

## 关联口径

- **图上机构同名**：原图直接书写该卫所全称。
- **图上同名地名关联**：图上书写地名（如“海門”），映射至表格对应的“海门卫”；此处不使用现代经纬度换算，也不声称图上地名恰为城址所在的精确位置。
- **图上两所合称**：原图“石浦二所”只创建一枚图像标记，叙述石浦前、后二所的共同沿革。
- 表格中的所级隶属关系依照《明代浙东海防建制_五府历史方位与GIS精定位版.xlsx》工作表“重检_15卫32所基准”。
- 网站每个节点使用 `name` 作标题，`history` 作标题下方的历史沿革，`source` 与 `mapLabel` 作文献和古图原文信息。来源表行号另存于 `sourceRow` 和 `heritageSourceRow`，便于后续复查。
- “桃渚所”的建置年代以遗址表“桃渚城”沿革所载洪武三十年为正文口径，建置工作表中的不同记述不直接混入网页。

## 网站数据文件

```text
index.html
assets/
  ming-zhejiang-map.jpg
  vedio.mp4
  historical-map-verified.json   ← 网站读取的当前公开点位
  historical-map-verified.csv    ← 同源数据可核查副本
```

图像坐标以原图左上角为原点，X 向右、Y 向下。只表示文字的图像锚点，不用于确认现代遗址的地理测绘坐标。

## 使用方法

打开网页，可以启用摄像头、握拳保持2秒解锁，然后张开手掌用圆形光圈探索；也可以点击“鼠标体验”。右上角“卫所定位”按六卫分组，点击各条目可以跳转图面并查看其历史沿革。右下角摄像头预览继续以高斯模糊保留隐私，并绘制手部骨骼线条。

网页在 GitHub Pages 静态托管，依赖在线 Three.js、MediaPipe WASM 和手势模型资源。本地可在仓库根目录运行 `python3 -m http.server 8080` 后访问 `http://localhost:8080`。
